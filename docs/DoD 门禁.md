# DoD 门禁定义（Definition of Done）

> 版本：v1 · 2026-08-18 · 依据：`需求说明书-终版.md` §6 验收 · `产品说明书-终版.md` §7 指标 · `docs/指标口径.md`
> 用途：交付能力/阶段时的**完成定义**；逐项可勾选，反指标为硬线。
> 冲突裁决：DoD 与验收冲突时以 `需求说明书-终版.md` §6 为准。

---

## 1. 能力/功能交付 DoD（每项能力通用）

- [ ] 对应需求 RQ-xxx 的验收锚点（F/S/UX/NFR）已实现且可验证
- [ ] 正向验收项达标（按 `docs/指标口径.md` 建档）
- [ ] 反指标不触线：AI 误执行事故 = 0 · 审批绕过 = 0 · 高危未走审批 = 0
- [ ] AI 相关变更过评测门禁（高危意图识别集召回 100%，`AI评测策略.md`）
- [ ] 关键路径有测试：happy + error + edge
- [ ] 审计五元组留痕可查（RQ-831）
- [ ] 安全专项：红蓝对抗 Critical/Major 项闭合（`AI红蓝对抗报告.md` 修复验收清单）

## 2. 阶段级 DoD（对应 `产品说明书-终版.md` §10 路线图）

**现在（Now，阶段 1–2）云 API 基础闭环**
- [ ] 云 API 模型链路可用（低成本/强推理/Agent 按场景路由；本地模型配置为兜底）
- [ ] 监控 + 知识库接入
- [ ] 普通用户可用大白话查知识、查服务器状态；知识首问 >80%（开发目标值）
- [ ] 审计留痕可查

**下一步（Next，阶段 3–4）执行闭环 + 零信任**
- [ ] 执行闭环 + Agent 编排
- [ ] 能力×角色矩阵落地，服务端强制校验（`产品说明书-终版.md` §4.2）
- [ ] L5 统一入口 + mTLS + WebAuthn + 高危审批 + 全量审计
- [ ] 高危审批双人 / 超时默认拒绝 / 幂等 达标（R1–R3）

**未来（Later，阶段 5–6）生产模型 + 自进化**
- [ ] 多模型智能路由（¥50–80/月）+ 灰度（1%→10%→50%→100%）+ 成本阈值告警
- [ ] 知识首问 >85%（生产目标值）
- [ ] 故障案例写回 Wiki、FAQ 自动生成

## 3. 门禁执行

- 逐阶段门禁：该阶段全部 DoD 勾选 **且** 反指标 = 0 → 放行下一阶段。
- 任一反指标触线 → 阶段冻结，整改后复验。
- 每次放行记录归档（阶段 / 日期 / 勾选证据 / 反指标读数）。
