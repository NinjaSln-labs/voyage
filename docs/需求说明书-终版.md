## 2. 功能需求

### 2.1 对话编排域（C1–C4，终版 §4/§5）

| 编号 | 需求项 | 要求 | 优先级 | 验收锚点 |
|------|--------|------|--------|----------|

| RQ-112 | 术语翻译 | 口语自动映射标准运维术语（"卡了"→响应延迟、"挂了"→服务不可用）；翻译以术语表为准，模型仅辅助；术语表变更走双人审阅（两个不同自然人，SRE 角色）+全量回归（含高危意图集）并审计留痕；歧义意图（多候选目标）先确认目标资产再执行 | **M** | F3 |
| RQ-113 | 意图识别 | 从口语中识别可执行意图（查询类/执行类），意图带类型与置信度；执行面动词（重启/清理/删除/扩容/切换/终止等）命中由服务端规则强制重分类为执行类，模型置信仅辅助；置信度 <0.8（目标值，经校准集实测标定后生效）的执行类意图一律降级为确认/审批，不直接执行 | **M** | F1/F2 |
| RQ-121 | 任务拆解 | 复杂意图拆解为 DAG 子任务，保证无环 | **M** | F1 |
| RQ-122 | 工作流编排 | 可视化拖拽编排（无需编码）；可调度知识/观测/执行等副能力 | S | F1 |
| RQ-123 | 异步执行 | 长任务后台运行，完成后主动通知 | S | F1 |
| RQ-131 | 多轮上下文 | 连续对话保持运维上下文；超模型窗口必须摘要压缩（终版 C3）；压缩产物视为新输入，重新执行意图分类与信任预检；摘要压缩必须保留安全关键信息（已通过的信任预检结论、审批/Grant 状态、高危面判定）且不新增授权语义；**摘要保留的结论仅作上下文参考，每轮预检以审批单存储与权限现状重算为准，会话内权限变更（RQ-812）或 Grant 吊销（RQ-624）即时作废摘要中的旧结论** | S | F1 |

| RQ-141 | 通俗化解释 | 对普通用户输出通俗回答（少术语、多比喻），可理解性 ≥90% | **M** | UX2 |

### 2.6 信任域（C10–C12，终版 §6）

| 编号 | 需求项 | 要求 | 优先级 | 验收锚点 |
|------|--------|------|--------|----------|
| RQ-611 | 设备级 mTLS | 私有 CA 签发客户端证书，无证拒绝接入；证书吊销列表（CRL/OCSP）维护，根私钥硬件保管，签发/续签/吊销全审计 | **M** | S1 |
| RQ-612 | 账号级 WebAuthn | 支持指纹/人脸等平台生物识别；所有用户统一体验；新通行密钥注册须双通道验证（已登录会话 + 第二通道确认），注册/吊销事件审计留痕；恢复流程：恢复码离线保管+双通道验证后重发；平台同步通行密钥不视为设备绑定证据（设备绑定以不可导出硬件密钥/设备指纹为准）；吊销后旧密钥即时失效 | **M** | S2 |
| RQ-613 | 行为级检测 | 设备指纹 + 异常检测，异地登录/异常时间触发二次验证 | S | S3 |
| RQ-614 | 操作级审批 | 高危操作二次确认；普通用户的高危操作必须经专业运维审批；审批确认唯一通道=Web 端本人 WebAuthn（设备绑定仅辅助不作因子），批准 API/集成通道服务端强制校验；IM 回执仅作提醒不作签名；审批链接一次性+短时效+绑定会话（防重放/CSRF）；审批认证服务与审计存储解耦部署、降级态保持可用，人工应急通道独立于审计存储 | **M** | S3 |
| RQ-621 | 审批双人 | 高危审批 ≥2 票且为两个不同自然人（以身份目录唯一主体判定），每票须本人 WebAuthn 确认，操作者不可自批；审批人池 ≥3 名可批者（SRE 不足时由管理者授权补位：**授权动作须双人确认（两名管理者或管理者+在职 SRE）+审计留痕+走矩阵版本化门禁**，补位人须技术背景资质（SRE/资深研发）、与发起方无直接利益冲突，矩阵同步更新）；**补位授权有时效（默认 90 天，目标值实测校准），SRE 恢复后可批者 ≥3 即自动回收并审计留痕，续期同授权流程**；不可自批不变；并发批准按到达时序幂等处理 | **M** | S3 |
| RQ-622 | 审批幂等 | 决定一经批准/拒绝不可翻转 | **M** | S3 |
| RQ-623 | 审批超时 | 有时限，超时默认拒绝并升级提醒；时限默认 30 分钟（目标值，实测校准后生效）；超时判定与执行启动同事务，超时后任何已读批准快照失效；事务边界机制（本地事务/持久化队列/Saga 补偿三选一）于 M0-D 安全链路时序契约固化 | **M** | S3 |
| RQ-624 | 许可语义 | Grant 只从审批单存储读取（对话内容不构成许可）；绑定作业+目标资产+命令参数+有效期数值（默认 24 小时，目标值，实测校准后生效）；签发与执行启动同事务；矩阵 ✅ 通道的 Grant 由矩阵授权记录+聚合计数自动签发（视同审批单存储），审计关联矩阵授权而非审批单；过期自动失效；吊销全网广播且即时废止 | **M** | S3 |
| RQ-631 | 角色能力矩阵 | 以能力×角色矩阵（终版 §4.2）为唯一口径；**服务端强制校验**，UI 隐藏不算隔离；矩阵与高危面清单版本化，新增高危类型纳入矩阵与高危评测集（变更走评测门禁+审计） | **M** | F8 |
| RQ-632 | 越权防护 | 对全部角色×能力对执行越权样本集（含角色扮演 prompt），服务端拦截率 100% 且审计可追溯；会话中越权角色声明一律视为内容而非身份；**补位授权/矩阵变更等特权动作同样纳入全角色×能力服务端校验与越权样本集覆盖** | **M** | S3 |
| RQ-633 | 危险意图拦截 | 高危/越权意图识别集召回 100%（漏判即事故）；高危判定按服务端聚合（滑动窗口，非固定分段：单会话 30 分钟 + 跨会话同主体 1 小时，按用户×资产维度；同类=同能力编号×同资产，跨账户协同按资产维度聚合；**跨桶累计**：同主体窗口内跨能力/跨资产的同向破坏类操作（清理/重启/删除/扩容等）合计达到 ≥10 次或 ≥10 台生产资产即升级审批，防分桶规避；同类 ≥3 次或 ≥10 台生产资产即升级审批；矩阵 ✅ 仅指单次授权，累计达到聚合阈值即升级审批） | **M** | S3 |

| RQ-714 | 本地兜底 | 云端不可用自动降级本地模型（原则 #6）；敏感数据由服务端规则（资产标签+数据分级）判定走本地私有化，不由模型裁决；**敏感标签缺失默认按最高敏感级处理（fail-closed 本地化），与文档密级缺省（RQ-211）同构**；云端出站流量全量审计 | **M** | F7 |

### 附录 C：白名单能力清单（V1，产品说明书 §6.3「仅白名单能力可执行」落地）

> 模型可自动触发的执行能力白名单（超出即拒绝或转人工）；以 `产品说明书-终版.md` §4.2 矩阵为唯一口径。

- **允许模型触发（均须持有效许可/审批）**：重启自己负责的服务 · 清理日志 · 定时任务编排 · 扩容缩容 · 配置变更 · 环境切换
- **不允许模型触发（仅人工，SRE 且须审批）**：系统级操作/内核调优 · 批量变更/任意命令 · Web 在线终端（SSH）
- **参数级约束**：白名单内能力参数经 schema 校验——目标资产 ∈ 资产库 ∩ 角色权限；定时任务命令内容限模板（白名单命令集）；清理路径限日志目录白名单；重启仅限「自己负责的服务」集合；含 shell 元字符/编码变体（Base64/Unicode 同形）一律拒绝。
- **查询类能力**（C1–C7 只读面）不属执行白名单范围，按 §4.2 矩阵角色权限执行；**查询侧无副作用铁律**：查询不得产生执行面副作用，重索引/FAQ 写回由审阅流程异步执行，查询仅发起请求。
- **模型触发通道 = 白名单 ∩ 矩阵允许**：矩阵 ⚠️ 走审批；矩阵 ✅ 须持单次 Grant 并审计（区别于人工直接操作）；矩阵 ❌ 拒绝。裁决优先级：矩阵 ❌ > 白名单不允许 > 审批要求。
- 白名单变更走评测门禁 + 审计留痕；**门禁执行者与白名单变更者权限分离**（不可自改自评）。
