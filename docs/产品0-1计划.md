## 0. 目标与「1」的定义

- **0-1 终点（「1」）**：内测可用——四类角色经统一入口，用自然语言完成**查询 / 知识问答 / 受限执行**，高危操作走**双人审批**，全链路**审计留痕**；DoD（Now + Next）全过、反指标 = 0、评测门禁通过。
- **北极星指引**：非运维用户月自主完成查询/受限操作数（计数口径见 `docs/指标口径.md`）。
- **反指标硬线（全程）**：AI 误执行事故 = 0 · 审批绕过 = 0 · 高危未走审批 = 0。
- **范围红线（本计划不含）**：能力级不做清单（`产品说明书-终版` §3.3）；Later 后端能力仅作收尾预览，属 1→N。

## 2.5 技术选型与详细设计（阶段 0 · 规划）

> 本计划刻意不预绑技术栈（纯能力描述）；**选型与设计作为独立阶段在实现前完成**，产出决策记录（写于实施工作区，不回写基础文档，保持零绑定）。

### 2.5.1 技术选型与 POC
- **时机**：M0 基线后、M0-D/M1 前；按能力层逐一评估候选方案。
- **评估标准（顺序裁决）**：能力达标 ≥ 许可合规（强 copyleft 自用评估）≥ 成本（云 API 预算、硬件一次性）≥ 可维护性（配置驱动、可替换、契约测试覆盖）。
- **关键能力 POC（每项验证后才进实现）**：口语理解与术语翻译 · 受限执行（持有效许可链路）· 设备/账号认证 · 审计五元组链路。
- **产出**：选型决策记录（候选对比、选中理由、替换条件）；不改变本文档能力口径。

### 2.5.2 详细设计（实现前契约 · 按 DDD）
- **方法**：以 DDD 推导——从能力 C1–C17 与业务规则 R1–R11 建立**限界上下文 → 聚合（实体/值对象）→ 不变量 → 领域事件 → 仓储接口 → 统一语言/术语**，再落到实现契约。
- **输入种子**（基础文档天然提供）：`产品说明书-终版` §5.2（能力 C1–C17）· §6.2（R1–R11 业务规则）· §4.2（能力×角色矩阵）· §11（口语→标准术语）；`需求说明书-终版` §2（每一项的 RQ 需求化）；`AI红蓝对抗报告.md`（Critical/Major 逐条固化不变量）。
- **产出（实施工作区 DDD 设计交付物，不进 `docs/` 基础文档集）**：
  1) 限界上下文与统一语言（术语表）；
  2) 核心聚合设计 + 不变量清单（R1–R11 + 红蓝对抗 Critical/Major 逐条落地为不变量）；
  3) 领域事件目录（含审计五元组 schema）；
  4) 能力接口契约（跨上下文调用/返回语义）；
  5) 数据对象（资产 · 作业 · 审批单 · 意图 · 任务）；
  6) 能力×角色矩阵服务端强制落地（权限判定点）；
  7) 安全链路门禁时序（R1–R3）。
- **验收**：DDD 设计评审通过（不变量齐全、无孤儿规则、矩阵服务端强制），M1+ 实现与测试按此对齐。

## 3. 关键路径与依赖（DAG）

```
M0 基线（指标口径建档 · 评测集初建 · DoD 模板）

                     │
                     ▼
              M4 执行闭环（C8/C9/C2，持有效许可才启动）── R4/R9 硬门
```

## 6. 评测与门禁节奏（`AI评测策略.md`）

- **M0**：建评测集基线与首次快照（口语 ≥50 / 知识 ≥50 / 术语 ≥30 / 高危 ≥30 / 解释 ≥30）。
- **每次能力/模型/提示词变更**：过评测门禁；**高危意图识别集召回 100% 为硬线**，漏判即冻结。
- **M6 前**：全部评测集达标（口语 ≥85%、知识 >80%、术语 ≥90%、解释 ≥90%）；反指标读数 0。
- **梯度放量**（Later）：1% → 10% → 50% → 100%，每档对比基线（成功率/时延/成本）。

## 7. 度量与数据来源（`指标口径.md`）

- 北极星：审计事件流计数（会话意图完成 + 作业执行成功），自然月；M1 起即埋点建档。
- 反指标 R1/R2/R3：告警≥P2 + 回滚 + 审计异常 + 高危许可关联核对，月度计数，触线即冻结。
- 阈值以「目标值声明 → 实测基线」双态管理（`指标口径.md` §5）。

## 8. 迭代节奏与评审

- 里程碑逐个交付：每 M 完成后过 **DoD 勾选 + 反指标复核 + 评测门禁** 才进下一个 M。
- **每阶段评审会**：能力是否达成（锚点）· 反指标读数 · 指标口径是否需更新（变更流程）。
- 任一反指标 >0 → 该阶段冻结，整改后复验（`DoD 门禁.md` §3）。
- 记录归档：每次放行的阶段 / 日期 / 勾选证据 / 反指标读数。

## 9. 0-1 聚焦风险与对策（关联 `需求说明书-终版` §7 风险）

| 风险 | 0-1 对策 |
|------|---------|
| 口语理解/术语准确率不足 | 术语表优先（表为准）；口语评测集迭代回填；到达阈值才放行 |
| 审批摩擦拖累体验 | 分层动作（提示/确认/审批，R11）；把审批限制在高危面，低危自查不扰 |
| 范围蔓延 | 严守能力级不做清单 + MoSCoW M 级优先（1/2/4/8） |
| 数据/知识质量 | 知识源结构化整理高频文档；索引新鲜度标注 |
| 高成本失控 | 预算上限 + 超限自动降级本地兜底（`产品说明书-终版` §7 关键阈值） |
