# 产品路线图（Theme-based）

> 版本：v1 · 2026-08-18 · 依据：`需求说明书-终版.md` §5
> 用途：对外一句话视角的路线图（详情与里程碑以 `需求说明书-终版.md` §5 为准）。

## 现在（Now）——云 API 基础闭环

阶段 1-2：接入云 API 模型闭环（低成本/强推理/Agent 按场景路由）；监控 + 知识库接入；**普通用户可用大白话查知识、查服务器状态**（首问 >80%）。本地模型仅作兜底。

## 下一步（Next）——执行闭环 + 零信任安全

阶段 3-4：执行 + Agent 编排闭环；角色权限体系；自建 L5 统一入口 + mTLS + WebAuthn + 高危审批 + 全量审计（内测上线）。

## 未来（Later）——生产模型 + 自进化

阶段 5-6：多模型智能路由（低成本/强推理/Agent 云模型，¥50–80/月，首问 >85%）；灰度 + 成本阈值告警；故障案例自动写回 Wiki、FAQ 自生成（自进化）。
