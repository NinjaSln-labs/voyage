# 版本计划（行舟 · Voyage）

> 版本：v1.0 · 2026-08-25 · 地位：发布版本锚点与进入条件的唯一口径（里程碑交付计划见 `产品0-1计划.md` §4，本文只做版本映射，不复制里程碑定义）
> 规则：SemVer；每版本打 git tag（`v*`）+ CHANGELOG.md 记录；tag 只在对应门禁全绿后打

## 1. 当前定位

M0–M6 全部完成、六类真实适配器落地、real 链 E2E 实测通过、双轴审计闭环——功能已收口，但认证真实验签与评测三集制尚未闭合。据此当前状态定为 **v0.9.0-alpha**（功能完整预发布，不可上生产流量）。

## 3. 版本号约定

- **主版本**：领域契约破坏性变更（事件协议 schemaVersion 升位、authPort/execAdapterPort 等端口契约不兼容修改）
- **次版本**：新增 BC/适配器/能力白名单扩容（向后兼容）
- **修订号**：缺陷修复、审计修正、测试补充
- 预发布后缀：`-alpha`（内部）/ `-beta`（三集制内测）/ `-rc`（放量候选）；正式 tag 无后缀

## 4. 维护规则

- 打 tag 前置检查：`find impl -name "*.test.js"` 全量绿 + `git status` 干净 + HANDOFF §2 快照与实际一致
- CHANGELOG 按 Keep a Changelog 分节（Added/Changed/Fixed/Security），一版本一节，详情引用 git hash 不复制 commit message 全文
- 回滚口径：生产问题回退到上一个 `v*` tag；评测不达标自动回滚绑定「评测集版本号↔模型版本号」快照（`AI评测策略.md` §5）
