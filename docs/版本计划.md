## 6. 版本号约定

- **主版本**：领域契约破坏性变更（事件协议 schemaVersion 升位、authPort/execAdapterPort 等端口契约不兼容修改）
- **次版本**：新增 BC/适配器/能力白名单扩容（向后兼容）
- **修订号**：缺陷修复、审计修正、测试补充
- 预发布后缀：`-alpha`（内部）/ `-beta`（三集制内测）/ `-rc`（放量候选）；正式 tag 无后缀

## 7. 维护规则

- 打 tag 前置检查：`find impl -name "*.test.js"` 全量绿 + `git status` 干净
- CHANGELOG 按 Keep a Changelog 分节（Added/Changed/Fixed/Security），一版本一节，详情引用 git hash 不复制 commit message 全文
- 回滚口径：生产问题回退到上一个 `v*` tag；评测不达标自动回滚绑定「评测集版本号↔模型版本号」快照（`AI评测策略.md` §5）
