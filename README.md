# 行舟 · Voyage

> **潮平两岸阔，风正一帆悬** · *Smooth Sailing*

把**运维能力民主化**的 AI 运维平台：听得懂大白话，指挥得了系统。交付五层架构、零信任安全、模型中立的智能运维助手。

- 中文名：**行舟**（xíng zhōu）——"行"=运行/执行（运维本体），"舟"=系统之舟；出处：王湾《次北固山下》"客路青山外，**行舟绿水前**"
- 英文名：**Voyage**——远航；与"行舟"词根对位，读来即"系统之远航"
- 一句话目标：让 SRE、研发、产品、管理者都用自然语言安全地完成查询与受限操作（详见 [docs/需求说明书-终版.md](docs/需求说明书-终版.md)）
- 全球定位对位：同类 AIOps 产品都服务 on-call 工程师，行舟服务「不敢碰运维的人」——差异化 = 口语化低门槛 × 零信任审批（详见 [docs/产品说明书-终版.md](docs/产品说明书-终版.md)）
