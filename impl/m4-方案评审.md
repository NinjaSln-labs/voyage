## 2. 设计决策（含依据与理由）

### 2.1 作业聚合 Job（领域核心）

```
Job {
  id, creator, target, template, params(schema-ok),
  grantRef, aggregationEscalated(默认 false), status, nodeEffects[]
}
```

**状态机**：
```
queued ──(start 前置全过 + Grant 有效 + 未升级)──▶ running ──▶ completed / failed
  │                                                    └─(吊销,已启动)→ 完成留痕(INV-E5 已启动节点)
  │──(Grant 吊销/过期/审批拒绝,未启动)──▶ rejected(INV-E5 未启动节点)
  │──(聚合升级标志置位)──▶ suspended(INV-E2 挂起转审批)
  └──(审批通过后恢复)──▶ running
```

**关键设计决定**：
1. **聚合根持有 `nodeEffects[]`**（M0-D §5 数据对象字段）：批量作业按节点记录副作用状态——这是 INV-U1「批量按节点记录副作用状态」与 INV-E5「已启动节点完成+未启动节点拒绝」的结构性载体。单节点作业 = 1 个 effect。
2. **`aggregationEscalated` 是 Job 字段而非游离标志**：挂起态是 Job 状态机的显式状态（`suspended`），触发后需新 Grant 或审批恢复，杜绝 standing Grant 绕过（INV-E2 红蓝 R-07 闭合）。
3. **`params(schema-ok)` 在构造时即校验**（附录 C 参数级约束）——不允许「先建后查」的绕过窗口；shell 元字符/编码变体（Base64/Unicode 同形）在参数入口拒绝（INV-E3）。
4. **`grantRef` 绑定而非复制 Grant**：Job 持 grantRef，`exec.start` 时经 `trust.checkGrant` 端口校验 Grant 有效且匹配（jobRef/target/commandTemplate/paramsHash 全匹配，对齐 M3 `Grant.matches`）——不复制授权实体，防双源。

### 2.2 exec.start 前置校验链（判定点 3 服务端强制，INV-E1/E3）

按 M0-D §4 判定点 3 顺序串联（矩阵 ❌ > 白名单不允许 > 审批要求）：

```
exec.start(job, now)
  1. 结构校验：job 实例、参数合法（构造已保证，此处防御性复核）
  2. 白名单 ∩ 矩阵：capability ∈ 白名单（附录 C）且矩阵允许（矩阵端口，M5 接真实；本里程碑契约端口）
  3. 参数 schema：附录 C 四类约束（见 §2.4）
  4. Grant 校验：trust.checkGrant(grantRef, target, template, paramsHash)——有效 + 匹配 + 未吊销 + 未过期
  5. 聚合升级标志：job.aggregationEscalated 或 trust 侧聚合判定 → 置位即 suspended，不得启动
  6. 资产未退役：资产端口 checkActive(target)
  7. 审计先行：audit.write(五元组) 成功才下发执行（INV-U1 fail-closed）
  8. 下发 → JobStarted 事件 → status=running
失败任一步 → REJECTED（原因码）或 ERROR（技术失败 fail-closed），不进入执行
```

**失败语义（对齐 M0-D §4 接口失败语义）**：`REJECTED` 带原因码（`grant_invalid / capability_not_whitelisted / param_schema_rejected / asset_retired / aggregation_escalated / job_revoked`）；`ERROR`（审计端口失败等）不得继续执行链。

### 2.3 事件订阅（exec 消费 trust，INV-E5/E2/G3）

| M3 事件 | exec 处理 | 对应不变量 |
|---------|----------|-----------|
| `GrantIssued` | 关联 queued job → 可启动（执行侧重校验） | INV-G2/G4 |
| `GrantRevoked` | 未启动/排队 job → rejected（吊销即拒绝）；已启动节点 → 完成+审计留痕 | INV-E5 / INV-G3 |
| `GrantExpired` | 未启动 job → rejected（过期自动失效） | INV-G3 |
| `AggregationEscalated` | 关联 standing job → suspended（挂起转审批） | INV-E2 |
| `ApprovalRejected / ApprovalTimedOut` | 关联 job → rejected（审批终态） | INV-A2/A3 |

- **幂等**：订阅按 eventId 去重（跨 BC 协议 eventId 幂等键，对齐 M3/M2）——同事件重放不重复副作用。
- **原子语义声明**：吊销广播与节点调度原子（事件版本号）属 M5 Outbox 编排层；领域层以「事件版本号单调 + 重放去重」预留接口，本里程碑保证领域层判定一致。

### 2.4 参数 schema（附录 C 落地为可测规则）

| 附录 C 约束 | 落地规则 |
|------------|---------|
| 目标资产 ∈ 资产库 ∩ 角色权限 | 资产端口：target ∈ 资产库且未退役；角色端口：creator 对 target 有该能力权限（契约端口，M5 接真实） |
| 命令限模板（定时任务） | job.template ∈ 白名单命令集（常量表），禁止任意命令串 |
| 路径白名单（清理） | 清理类 capability：params.path 必须以白名单目录前缀开头（LOG_DIR_WHITELIST 常量） |
| 重启仅限自己负责的服务 | 重启类：target 必须 ∈ creator 负责集合（角色端口校验） |
| shell 元字符 / 编码变体拒绝 | 参数值扫描：shell 元字符集 `;|&$<>`\`(){}[]*?!~` 拒绝；Base64 特征（长度%4=0 且字符集∈base64 alphabet 且含 `=` padding）拒绝；Unicode 同形/全角→半角归一化后比对（复用 M2 normalize 思路） |
| 参数化调用不 shell 拼接 | 领域层只产出 `{template, params}` 结构化数据，绝不拼接命令字符串（执行适配器在 M5/M6，本里程碑以「无拼接方法」保证） |

### 2.5 凭据保险库（INV-E4 / RQ-411）

- Job/params **不允许出现凭据字段**（构造校验拒绝 `password/secret/token/credential` 键）。
- SSH 等凭据经凭据保险库端口引用（`credentialVault.ref`），凭据值**不入模型上下文/不入事件载荷**。
- 本里程碑落地：领域层凭据键拒绝 + 端口契约声明；真实保险库接 M5。

### 2.6 事件发布（exec 侧）

```
JobStarted   { jobId, creator, target, template, grantRef, paramsHash, startedAt }   (exec→audit/metric/notif)
JobCompleted { jobId, result, finishedAt, nodeEffects }                              (exec→audit/metric/notif)
JobFailed    { jobId, reason, finishedAt, nodeEffects }                              (exec→audit/metric/notif)
```
协议对齐：`schemaVersion=1 + eventId 幂等键 + 载荷深冻结`（对齐 M2/M3 事件协议，跨 BC 唯一契约）。

## 4. 测试规划（五类）

- **happy**：H1 白名单+Grant 有效+未升级 → running→completed；H2 定时任务（standing Grant 触发）；H3 参数 schema 合法通过；H4 审批后 GrantIssued 启动；H5 事件闭环发布 JobStarted/Completed。
- **error**：E1 非白名单能力拒绝（rm_rf_root 等）；E2 Grant 无效/过期/吊销拒绝；E3 参数含 shell 元字符/Base64/同形变体拒绝；E4 资产退役拒绝；E5 凭据键构造拒绝。
- **edge**：G1 聚合升级置位 → suspended（挂起不启动）；G2 审批拒绝/超时 → rejected；G3 已启动节点吊销 → 完成留痕（INV-E5）；G4 未启动节点吊销 → rejected；G5 deadline/有效期边界闭区间。
- **adversarial**：A1 事件重放幂等（同 eventId 不重复副作用）；A2 参数原型链保留键（__proto__ 等）；A3 超长参数/命令模板注入；A4 全角/零宽变体绕参数校验；A5 状态机终态全入口拒绝。
- **fault-tolerance**：F1 审计端口失败 → ERROR fail-closed 不执行；F2 事件总线未接线 → 不崩溃；F3 端口返回畸形 → 结构校验 fail-fast；F4 时间倒退（now 倒退）拒绝。
