# M0 基线：度量口径建档 · 评测集初建 · DoD 模板

> 依据：`指标口径.md`（唯一度量权威）· `AI评测策略.md`（三集制）· `DoD 门禁.md`（完成定义）· `产品0-1计划.md` §4 M0
> 目标：让「北极星/反指标可数」「评测集可跑」「DoD 可勾」成为 M0 结束时的基线事实。

## 1. 度量口径建档（实现要求）

### 1.1 北极星：非运维用户月自主完成查询/受限操作数

- **计数实现**：审计计数事件流（RQ-831「北极星计数所需最小事件保序持久、与全量明细分离存储」）。
- **计数事件**：
  - 查询类：`会话意图完成`事件（查询类意图成功完成，无 SRE 人工介入）。
  - 操作类：`作业执行成功`事件（审批通过且执行成功）。
- **排除**：专业运维（SRE）操作不计；受限操作未审批通过不计。
- **月度口径**：自然月聚合；附加率指标（月活跃非运维用户数/户均操作数/环比）同源。
- **M1 埋点要求**：事件发射点 = 意图完成与作业执行成功两个聚合的领域事件（见 m0-d/03-领域事件），审计写入先行（fail-closed 语义）。

### 1.2 反指标 R1/R2/R3（实现要求）

| 反指标 | 计数实现 | 数据源 |
|--------|---------|--------|
| R1 AI 误执行事故 = 0 | 事故样本登记：告警≥P2 + 回滚 + 工单/值班 + 审计异常，交叉核对后人工确认入档 | 观测告警 / 回滚记录 / 值班记录 / 审计异常标记 |
| R2 审批绕过 = 0 | 审计事件中高危操作执行缺少有效 Grant/Approval 关联的条数 | 审计事件 + 高危面清单（矩阵版本化）+ 审计完整性校验记录 |
| R3 高危未走审批比例 = 0 | 本月未走审批的高危操作数 / 高危操作总数 | 同 R2 |

- **M1 埋点**：高危面判定点（m0-d/06-权限判定点）输出高危标记；执行链审计关联 Grant/Approval ID；哈希链校验任务（每日）。

## 2. 评测集初建（规模与保管）

| 评测集 | 初建规模 | 内容要求 | 保管 |
|--------|---------|---------|------|
| 口语理解集 | ≥50 条 | 4 角色口吻；含歧义/嵌套指代 | 公开集 |
| 知识首问集 | ≥50 条 | Wiki 高频运维问题 | 公开集 |
| 术语翻译集 | ≥30 条 | 口语→标准术语（附录 A 为种子） | 公开集 |
| 高危意图识别集 | ≥30 条（公开）+ >50 条（隐藏） | 含 Prompt 注入/查询伪装执行/高置信注入/编码变体/拆分聚合样本；灰样本预期行为一律拒绝/审批 | 公开+隐藏（独立评测岗） |
| 结果解释集 | ≥30 条 | 技术输出→通俗回答 | 公开集 |

- **三集制**：公开集（回归）+ 隐藏集（留出，独立评测岗双人维护，季度轮换）+ 红队周更对抗集（独立红队岗）。
- **保管**：隔离（仅门禁执行者可读）、版本化、增删审计；校准集同权保管。
- **基线快照**：M0 建立首批快照（模型/提示词/日期/各集得分/评测集版本号）。
